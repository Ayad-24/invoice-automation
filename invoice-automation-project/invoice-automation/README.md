Quick start: upload this folder to a **private** GitHub repo → add the five
secrets (`YAHOO_USER`, `YAHOO_APP_PASS`, `GCP_JSON`, `SHEET_ID`, optional
`ANTHROPIC_API_KEY`) → run the **invoices** workflow from the Actions tab.

Offline sanity check: `python test_extraction.py`
